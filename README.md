# informe-requisitos
# 🍽️ Sazón — Célula 3

## 1. Descripción del proyecto

Sazón es una plataforma digital que permite a los usuarios registrar los ingredientes disponibles en su hogar y recibir sugerencias de recetas que pueden preparar con ellos.

El sistema busca facilitar la preparación de alimentos mediante la búsqueda de ingredientes, la identificación de coincidencias con recetas, la sugerencia de sustituciones y la identificación de los ingredientes que hacen falta para completar una preparación.

## 2. Objetivo del repositorio

Este repositorio tiene como finalidad desarrollar de manera colaborativa el informe de requisitos del proyecto Sazón, documentando sus objetivos, alcance, problemática, tecnologías y demás elementos necesarios para definir el funcionamiento del sistema.

El trabajo se realizará mediante Git y GitHub, permitiendo que cada integrante contribuya al documento y que los cambios sean revisados e integrados de manera organizada.

## 5. Metodología de trabajo con GitHub

El repositorio principal será público y estará administrado por el líder del equipo.

Cada integrante deberá:

1. Ingresar al repositorio principal de Sazón.
2. Realizar un Fork para crear una copia del repositorio en su propia cuenta de GitHub.
3. Clonar su Fork en el computador para trabajar localmente.
4. Desarrollar las actividades asignadas y registrar los cambios mediante commits.
5. Subir los cambios a su propio Fork.
6. Crear un Pull Request dirigido al repositorio principal para solicitar la integración de sus aportes.

El líder del equipo revisará los Pull Requests y aprobará e integrará los cambios que correspondan.

## 6. Normas de colaboración

- Cada integrante debe trabajar principalmente en las actividades que tiene asignadas.
- Los cambios deben estar relacionados con el desarrollo del informe de requisitos.
- Los commits deben tener mensajes claros que describan las modificaciones realizadas.
- Antes de integrar cambios, se debe verificar que no existan modificaciones que sobrescriban el trabajo de otros integrantes.
- Las modificaciones al documento principal deben coordinarse entre los integrantes para evitar conflictos de versiones.
